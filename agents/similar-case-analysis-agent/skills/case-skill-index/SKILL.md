# case_skill_index

## 作用

描述通用类案分析 POC 的 Skills 化索引规则。

本 Skill 不绑定任何特定领域。它用于说明类案材料应如何被组织为可检索对象，以及 `index.json` 中的通用规则如何参与检索。

## 数据组织约定

每个类案应至少包含：

- `case_id`：类案唯一标识；
- `title`：类案标题或名称；
- `metadata`：任意结构化元数据；
- `chunks`：按段落或逻辑片段切分的原文内容；
- `chunk_id`：原文片段唯一标识。

元数据字段不要求固定。字段差异应保留在 `metadata` 中，由检索阶段按需匹配。

## Skill 规则文件

通用规则定义在当前目录的：

```text
index.json
```

规则只表达通用检索意图，例如：

- 样本范围检索；
- 关键因素证据检索；
- 结果与理由检索；
- 对比分析检索；
- 全文关键词兜底检索。

## 约束

- 不生成向量。
- 不使用 embedding 模型。
- 不写入向量数据库。
- 不依赖特定行业字段。
- 不把具体领域词表硬编码到规则中。
