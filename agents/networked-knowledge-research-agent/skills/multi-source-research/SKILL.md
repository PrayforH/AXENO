# 多源研究

## 执行顺序

1. 判断问题属于内部知识、OpenAI 官方文档、公开互联网或混合研究。
2. 选择最窄且最权威的来源开始检索。
3. 对会显著影响结论的事实进行交叉验证。
4. 合并重复来源，记录冲突和缺口。
5. 输出结论、依据、引用和不确定性。

## 来源优先级

- 内部或专用语料：使用已注册的知识库 MCP。
- OpenAI 产品与 API：通过 Tavily 检索 OpenAI 官方域名。
- 最新公开信息：使用 Tavily。
- 用户附件：先读取原始文件，再使用联网来源补充。

## 约束

- 只使用已注册的只读 MCP。
- 不把搜索摘要当作完整原文。
- 不伪造调用结果、引用、日期或统计数字。
- 来源冲突时并列呈现，不自行消除冲突。
