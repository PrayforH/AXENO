# 公文常用词语与套语速查

## 一、开头用语

### 按文种分类

| 文种 | 常用开头 |
|------|---------|
| 通知 | 为深入贯彻……，现将……通知如下 |
| | 根据……要求，经研究，决定…… |
| | 为进一步加强……，现就有关事项通知如下 |
| 通报 | 现将……情况通报如下 |
| | 为……，现对……进行通报 |
| 报告 | 根据……要求，现将……情况报告如下 |
| | 现将……工作情况报告如下 |
| 请示 | 为（解决/落实/推进）……，特向……请示如下 |
| | 根据……需要，拟……，妥否，请批示 |
| 批复 | 你（单位）《关于……的请示》（文号）收悉。经研究，现批复如下 |
| 函 | 贵（单位）《关于……的函》收悉。经研究，现函复如下 |
| | 为（商洽/解决）……事宜，现致函如下 |
| 纪要 | ……年……月……日，……（主持人职务、姓名）主持召开……会议 |
| 决定 | 为……，经……研究，决定…… |
| 意见 | 为（贯彻落实/深入推进）……，现提出如下意见 |

### 按引发事由分类

| 事由类型 | 用语 |
|---------|------|
| 依据上级文件 | 根据《……》（文号）要求 / 按照……精神 / 为贯彻落实…… |
| 依据法律法规 | 依据《……法》第X条规定 / 根据……有关规定 |
| 依据工作需要 | 为进一步做好…… / 为切实加强…… / 为有效推进…… |
| 依据会议精神 | 根据……会议精神 / 按照……会议部署 |

## 二、过渡衔接用语

| 场景 | 用语 |
|------|------|
| 引出下文 | 现就有关事项（通知/明确/函告）如下 |
| 总结上文 | 为此 / 据此 / 鉴于此 / 综上所述 |
| 表示决定 | 经研究决定 / 经会议研究决定 / 经……批准 |
| 补充说明 | 同时 / 此外 / 另外 / 需要指出的是 |
| 转折 | 但是 / 然而 / 不过 / 尽管如此 |
| 递进 | 不仅……而且…… / 在此基础上 / 进一步 |
| 并列 | 一是……二是……三是…… / 一方面……另一方面…… |

## 三、要求督办用语

| 强度 | 用语 |
|------|------|
| 强制执行 | 请遵照执行 / 请严格执行 / 请认真贯彻执行 |
| 认真落实 | 请结合实际，认真抓好落实 / 请切实做好……工作 |
| 高度重视 | 各（单位/部门）要高度重视，切实加强…… |
| 强化责任 | 要强化责任意识，确保……落到实处 |
| 限时完成 | 请于……前完成 / 请在……日内报送 |
| 报送要求 | 请将……情况于……前报送…… |

## 四、结尾用语

| 文种 | 结尾语 |
|------|--------|
| 通知 | 特此通知。 |
| 通报 | 特此通报。 |
| 报告 | 特此报告。 |
| | 以上报告，请审阅。 |
| 请示 | 以上请示，请批复。 |
| | 妥否，请批示。 |
| | 以上请示如无不妥，请批转……执行。 |
| 批复 | 此复。 |
| 函（去函） | 盼复。/ 请予支持为盼。/ 请予协助为荷。 |
| 函（复函） | 此复。/ 特此函复。/ 特此函达。 |
| 意见 | 以上意见如无不妥，请批转……执行。 |

**注意**：结尾语独占一行，前面空两格。

## 六、发文字号格式

格式：**机关代字〔年份〕序号号**

| 要素 | 规则 | 示例 |
|------|------|------|
| 机关代字 | 发文机关的规范化简称 | 国发、X办发、X民字 |
| 年份 | 六角括号〔〕包裹 | 〔2025〕 |
| 序号 | 阿拉伯数字，不编虚位 | 1号（不写01号） |

常见机关代字格式：
- 国务院：国发
- 省级政府：X政发（如京政发、沪府发）
- 部委：X部发
- 办公厅/室：X办发

## 七、标题拟制规范

### 标准格式

**发文机关名称 ＋ 关于 ＋ 事由 ＋ 的 ＋ 文种**

示例：
- XX市人民政府关于加强城市管理工作的通知
- XX局关于2025年度工作情况的报告
- XX厅关于申请增加编制的请示

### 注意事项

1. 标题中除法规名称加书名号外，一般不用标点符号
2. 标题可省略发文机关名称（版头已有时）
3. 标题应准确概括公文主要内容
4. 回行时应保持词意完整，排列为梯形或菱形
