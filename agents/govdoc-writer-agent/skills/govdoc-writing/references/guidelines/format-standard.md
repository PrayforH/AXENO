# GB/T 9704 党政机关公文格式标准

依据 GB/T 9704-2012《党政机关公文格式》。

## 一、纸张与版面

| 参数 | 规格 |
|------|------|
| 纸张 | A4（210mm × 297mm） |
| 上边距（天头） | 37mm ± 1mm |
| 下边距 | 35mm ± 1mm |
| 左边距（订口） | 28mm ± 1mm |
| 右边距 | 26mm ± 1mm |
| 版心尺寸 | 156mm × 225mm |
| 每面行数 | 22 行 |
| 每行字数 | 28 字 |
| 行距 | 正文 28.5 磅 |

## 二、字体字号规范

| 要素 | 字体 | 字号 | 颜色 |
|------|------|------|------|
| 份号 | 黑体 | 三号 | 黑色 |
| 密级和保密期限 | 黑体 | 三号 | 黑色 |
| 紧急程度 | 黑体 | 三号 | 黑色 |
| 发文机关标志 | 小标宋体 | — | 红色 |
| 发文字号 | 仿宋 | 三号 | 黑色 |
| 签发人标签 | 仿宋 | 三号 | 黑色 |
| 签发人姓名 | 楷体 | 三号 | 黑色 |
| 标题 | 小标宋体 | 二号 | 黑色 |
| 主送机关 | 仿宋 | 三号 | 黑色 |
| 正文 | 仿宋 | 三号 | 黑色 |
| 一级标题 | 黑体 | 三号 | 黑色 |
| 二级标题 | 楷体 | 三号 | 黑色 |
| 三级标题 | 仿宋加粗 | 三号 | 黑色 |
| 四级标题 | 仿宋 | 三号 | 黑色 |
| 附件说明 | 仿宋 | 三号 | 黑色 |
| 发文机关署名 | 仿宋 | 三号 | 黑色 |
| 成文日期 | 仿宋 | 三号 | 黑色 |
| 抄送机关 | 仿宋 | 四号 | 黑色 |

## 三、正文标题层级

| 层级 | 编号格式 | 字体 | 示例 |
|------|---------|------|------|
| 第一层 | 一、 | 黑体三号 | 一、总体要求 |
| 第二层 | （一） | 楷体三号 | （一）指导思想 |
| 第三层 | 1. | 仿宋加粗三号 | 1. 明确工作目标 |
| 第四层 | （1） | 仿宋三号 | （1）加强组织领导 |

注意：
- 第一层编号后用顿号"、"，标题独占一行，末尾不加标点
- 第二层编号用括号，标题独占一行，末尾不加标点
- 第三层编号后用下角圆点"."，标题后可接正文，用句号分隔
- 第四层编号用括号，标题后可接正文，用句号分隔

## 四、公文三大部分

### 4.1 版头（红色分隔线以上）

| 要素 | 位置和规则 |
|------|-----------|
| 份号 | 版心左上角第一行，顶格 |
| 密级和保密期限 | 份号下一行（无份号则在第一行），顶格 |
| 紧急程度 | 密级下一行，顶格 |
| 发文机关标志 | 居中排布，上边缘至版心上边缘 35mm |
| 发文字号 | 发文机关标志下空二行，居中；联合行文只标主办机关发文字号 |
| 签发人 | 上行文须标注，居右，"签发人："后标签发人姓名 |
| 版头分隔线 | 发文字号下 4mm，红色，与版心等宽 |

### 4.2 主体（红色分隔线以下至版记之前）

| 要素 | 位置和规则 |
|------|-----------|
| 标题 | 分隔线下空二行，居中，二号小标宋体 |
| 主送机关 | 标题下空一行，左空一字（顶格），后标全角冒号 |
| 正文 | 主送机关下一行开始，每段左空二字，回行顶格 |
| 附件说明 | 正文下空一行，左空二字，"附件："后标附件名称 |
| 发文机关署名 | 成文日期之上，居中 |
| 成文日期 | 署名之下，居中，阿拉伯数字 |

**多个附件标注格式**：
```
附件：1. 第一个附件名称
      2. 第二个附件名称
```

### 4.3 版记（末页分隔线以下）

| 要素 | 位置和规则 |
|------|-----------|
| 版记分隔线 | 首条和末条粗线（0.35mm），中间细线（0.25mm） |
| 抄送机关 | "抄送："后标机关名称，四号仿宋，末尾用句号 |
| 印发机关和日期 | 末条分隔线之上一行，左空一字标机关名，右空一字标日期 |

## 五、用印规则

- 单一机关：印章居中骑年盖月（印章下弧压在成文日期上）
- 联合行文：主办机关印章在前（左），每排最多 3 个
- 不加盖印章的公文：署发文机关名称

## 六、页码

- 位置：版心下边缘之下一行，数字左右各放一条一字线
- 格式：`— 1 —`
- 规则：单页居右空一字，双页居左空一字；空白页不标页码
