# 行文规则与写作规范

## 一、行文关系与规则

### 1.1 行文方向

| 方向 | 文种 | 说明 |
|------|------|------|
| 上行文 | 请示、报告 | 向上级机关行文 |
| 下行文 | 通知、通报、批复、决定、命令 | 向下级机关行文 |
| 平行文 | 函 | 向同级或不相隶属机关行文 |

### 1.2 核心行文规则

1. **请示一文一事**：每份请示只能请示一个事项，不得在一份请示中同时请示多件事
2. **报告不得夹带请示**：报告中不得夹带请示事项（否则请示事项可能被忽略）
3. **不得越级行文**：一般不得越过直接上级向更高层级行文（紧急情况除外，但须同时抄送被越过的上级）
4. **主送机关要明确**：上行文原则上主送一个上级机关，不得多头主送
5. **受双重领导的机关**：向一个上级机关行文时，必要时抄送另一个上级机关

## 二、语体风格

### 2.1 总体要求

公文语言应当：**庄重、简明、准确、平实**。

### 2.2 禁止用法

| 类别 | ❌ 禁止 | ✅ 应改为 |
|------|--------|----------|
| 口语化 | 搞好、弄清楚、抓紧办 | 做好、查明、加快办理 |
| 文学化 | 春风化雨般的关怀 | 大力支持 |
| 网络用语 | 点赞、给力、打卡 | 肯定、有力、到岗 |
| 绝对化 | 彻底杜绝、永远不会 | 切实防范、有效避免 |
| 模糊表述 | 有关部门、相关人员 | XX局、项目负责人XX |
| Markdown 列表 | - 第一项 / * 第二项 | 一是……二是…… |

### 2.3 列举方式

公文中列举多项内容时，禁止使用 Markdown 列表符号，应使用以下方式：

**并列列举**：
- 一是……二是……三是……
- 第一，……第二，……第三，……
- 首先，……其次，……最后，……

**条款列举**（作为独立段落）：
- 一、……
- （一）……
- 1. ……

## 三、数字使用规范

依据 GB/T 15835《出版物上数字用法》：

| 场景 | 用法 | 示例 |
|------|------|------|
| 成文日期 | 阿拉伯数字 | 2025年4月20日 |
| 发文字号年份 | 阿拉伯数字 + 六角括号 | 〔2025〕 |
| 发文字号序号 | 阿拉伯数字（不编虚位） | 1号（不写01号） |
| 统计数据 | 阿拉伯数字 | 增长12.5%、投入300万元 |
| 概数 | 中文数字 | 三五天、七八十人、十几个 |
| 相邻两数概数 | 中文数字（中间不用顿号） | 二三十人（不写二、三十人） |
| 正文标题序号 | 中文数字 | 一、（一）等 |
| 多位整数 | 阿拉伯数字（千分位可用空格） | 12 000人、3 500万元 |
| 引用文件年份 | 阿拉伯数字 | 《关于……的通知》（X办发〔2024〕3号） |

## 四、标点符号规范

| 符号 | 正确用法 | 常见错误 |
|------|---------|---------|
| 书名号《》 | 法规、文件名称 | ❌ 用于活动名称、项目名称 |
| 六角括号〔〕 | 仅用于发文字号的年份 | ❌ 用方括号 [] 或圆括号 () |
| 顿号、 | 并列词语之间 | ❌ 相邻数字表概数时加顿号 |
| 分号；| 并列分句之间 | ❌ 最后一个分句用分号（应用句号） |
| 冒号：| 总结下文、引出说明 | ❌ 同一句中用两个冒号 |
| 句号。| 一级标题末尾不加标点 | ❌ 一级标题后加句号 |

**注意**：
- 一级标题和二级标题独占一行时，末尾不加标点
- 三级、四级标题如果接正文，标题后用句号
- 结尾语如"特此通知。"独占一行

## 五、各文种正文结构逻辑

### 通知类

```
发文缘由（为……/根据……）
一、总体要求
二、主要任务 / 工作内容
    （一）具体任务1
    （二）具体任务2
三、工作要求 / 保障措施
结语：特此通知。
```

### 报告类

```
开头（现将……报告如下）
一、基本情况
二、主要做法及成效
    （一）做法1
    （二）做法2
三、存在的问题和不足
四、下一步工作计划
结语：特此报告。/ 以上报告，请审阅。
```

### 请示类

```
请示缘由（为……/根据……需要）
请示事项（具体内容）
结语：以上请示，请批复。/ 妥否，请批示。
```

### 函类

```
事由说明
具体事项
结语：盼复。/ 此复。/ 特此函达。
```

### 纪要类

```
会议概况（时间、地点、主持人、参会人员）
会议指出 / 会议强调 / 会议要求
议定事项一
议定事项二
```

### 决定类

```
决定缘由（经……研究决定）
一、决定事项1
二、决定事项2
三、执行要求
```

## 六、段落写作要点

1. **每段应有明确主旨**：一段说一件事，段首句点明核心
2. **段落衔接**：段与段之间用"同时""此外""另外"等过渡
3. **措施具体**：不写空话套话，每条措施要有明确的责任主体、时间节点、预期效果
4. **数据支撑**：汇报成绩用数据说话，避免"取得了一定成效"等模糊表述
5. **行文简洁**：能用一句话说清的不用两句，能用短句不用长句
