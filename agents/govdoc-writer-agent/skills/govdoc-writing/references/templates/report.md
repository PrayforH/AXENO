# 报告 — 写作模板

docx-report type: `report`

## 适用场景

- 向上级机关汇报工作、反映情况
- 答复上级机关的询问
- 报送需上级机关知晓的事项

行文方向：**上行**

## 标题格式

- 关于XXX工作的报告
- 关于XXX情况的报告
- XXX工作报告

## 正文结构

### 结构一：工作报告（最常见）

```
开头（现将……报告如下）
一、基本情况 / 总体概况
二、主要做法及成效
    （一）做法1
    （二）做法2
三、存在的主要问题
四、下一步工作计划 / 打算
结语：特此报告。
```

### 结构二：情况报告

```
开头（根据……要求，现将……报告如下）
一、基本情况
二、原因分析
三、已采取的措施
四、下一步工作建议
结语：以上报告，请审阅。
```

## 写作要点

1. **禁止夹带请示**：报告中不得夹带请示事项
2. 数据要具体：用数字说话，避免"取得了一定成效"等模糊表述
3. 问题部分要实事求是，不回避不粉饰
4. 计划部分要有针对性，与问题部分对应
5. 结语用"特此报告。"或"以上报告，请审阅。"
