# 函 — 写作模板

docx-report type: `letter`

## 适用场景

不相隶属机关之间：
- **商洽函**：商洽工作事项
- **询问函**：询问具体问题
- **答复函**：答复对方询问
- **请批函**：向有关主管部门请求批准
- **告知函**：告知对方有关事项

行文方向：**平行**（语气要平等协商）

## 标题格式

- XX机关关于XXX的函
- XX机关关于XXX的复函

## 正文结构

### 去函（商洽函/询问函/请批函）

```
事由说明段（引出背景和原因）
具体事项段（列明商洽/询问/请求内容）
结语：盼复。/ 请予支持为盼。/ 请予批准。
```

### 复函（答复函）

```
引述来文（贵单位《关于……的函》收悉）
答复意见
结语：此复。/ 特此函复。
```

## 写作要点

1. **语气平等**：函用于不相隶属机关之间，不能用指令性用语（"要求""必须"）
2. **正确称谓**：用"贵（单位）""你（处/局）"，不用"该"
3. 去函用"请""盼""望"等商请语气
4. 复函开头须引述来文标题和文号
5. 函的正文通常不分多级标题，结构简洁
6. 联系方式（contact）可选，便于对方沟通
