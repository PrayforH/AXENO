# 会议纪要 — 写作模板

docx-report type: `minutes`

## 适用场景

记载会议主要情况和议定事项。

注意：纪要不是普通公文行文，不标注主送机关，发文字号用"纪要号"，标题不加书名号。

## 标题格式

- XX会议纪要（不加书名号）
- XX座谈会纪要
- 第X次XX工作会议纪要

## 正文结构

```
会议概况段（时间、地点、主持人、参会人员）
会议指出/强调/要求段（概述性内容）
议定事项一
议定事项二
……
```

## 写作要点

1. **概况段要素齐全**：时间、地点、主持人、参会人员缺一不可
2. 议定事项要具体明确，包含：做什么、谁来做、什么时间完成
3. "会议指出""会议强调""会议要求"是常用引导语
4. 纪要没有固定结尾语，以最后一个议定事项结束
5. 参会人员较多时可概括写（如"XX等部门负责同志"）
