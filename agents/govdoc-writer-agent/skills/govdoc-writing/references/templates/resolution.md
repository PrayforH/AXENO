# 请示与批复 — 写作模板

docx-report type: `resolution`

## 一、请示

### 适用场景

向上级机关请求指示、批准。行文方向：**上行**。

### 标题格式

XX机关关于XXX的请示

### 正文结构

```
请示缘由段（说明背景、依据和理由）
请示事项段（具体请求内容）
结语：以上请示，请批复。/ 妥否，请批示。
```

### JSON sections 示例

```json
{
  "type": "resolution",
  "subtype": "请示",
  "gov_org": "XX市人力资源和社会保障局",
  "doc_num": "X人社请〔2025〕3号",
  "title": "关于增设基层劳动保障服务站的请示",
  "send_to": "市人民政府",
  "date": "2025年4月10日",
  "sections": [
    {
      "heading": "",
      "level": 1,
      "paragraphs": [

      ]
    },
    {
      "heading": "",
      "level": 1,
      "paragraphs": [
        "一是拟在新建社区增设劳动保障服务站20个，实现城市社区全覆盖。二是每个服务站配备工作人员2至3名，所需人员从现有编制中调剂解决。三是所需设备和运行经费约180万元，拟从就业专项资金中列支。"
      ]
    },
    {
      "heading": "",
      "level": 1,
      "paragraphs": [
        "以上请示，请批复。"
      ]
    }
  ],
  "conclusion": ""
}
```

### 写作要点

1. **一文一事**：每份请示只请示一个事项
2. **主送一个**：只主送一个上级机关，不多头主送
3. 缘由充分：说清"为什么要请示"，数据支撑
4. 事项明确：说清"请求批准什么"，具体可操作
5. 结语必备：必须有"请批复""请批示"等期复用语

---

## 二、批复

### 适用场景

答复下级机关的请示。行文方向：**下行**。

### 标题格式

XX机关关于XXX的批复

### 正文结构

```
引述来文（你单位《关于……的请示》收悉）
批复意见（原则同意/不予同意 + 具体意见）
结语：此复。
```

### JSON sections 示例

```json
{
  "type": "resolution",
  "subtype": "批复",
  "gov_org": "XX市人民政府",
  "doc_num": "X府批〔2025〕15号",
  "title": "关于同意增设基层劳动保障服务站的批复",
  "send_to": "市人力资源和社会保障局",
  "date": "2025年4月20日",
  "sections": [
    {
      "heading": "",
      "level": 1,
      "paragraphs": [
        "你局《关于增设基层劳动保障服务站的请示》（X人社请〔2025〕3号）收悉。经研究，现批复如下。"
      ]
    },
    {
      "heading": "",
      "level": 1,
      "paragraphs": [
        "原则同意在新建社区增设劳动保障服务站20个。在具体实施中，请注意以下事项：一是合理选址布局，优先覆盖服务需求较大的社区。二是人员配置要精干高效，加强业务培训。三是经费使用要严格按照就业专项资金管理规定执行，确保专款专用。"
      ]
    },
    {
      "heading": "",
      "level": 1,
      "paragraphs": [
        "此复。"
      ]
    }
  ],
  "conclusion": ""
}
```

### 写作要点

1. 开头须引述请示的标题和文号
2. 态度明确："同意""原则同意""不予同意"
3. 如有附加条件或注意事项，在批复意见中一并说明
4. 批复应及时，不得拖延
