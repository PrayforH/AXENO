# 决定 — 写作模板

docx-report type: `decision`

## 适用场景

- 对重要事项作出决策和部署
- 奖惩有关单位和人员
- 变更或撤销下级不适当的决定

行文方向：**下行**

## 标题格式

- XX机关关于XXX的决定
- XX机关关于表彰XXX的决定
- XX机关关于撤销XXX的决定

## 正文结构

### 结构一：决策部署类

```
决定缘由段（经……研究，决定……）
一、决定事项1
二、决定事项2
三、执行要求
```

### 结构二：表彰奖励类

```
表彰缘由段
受表彰名单
号召学习段
```

## 写作要点

1. **语气坚决明确**：决定是决策性文件，不用商量口吻（"建议""希望"）
2. 缘由段说明决策依据（会议决定、上级要求等）
3. 事项要具体可操作：明确责任主体、时间节点、量化指标
4. 最后通常有"加强组织实施"或"执行要求"部分
5. 决定一般没有固定结尾语，以最后一个事项或要求结束
