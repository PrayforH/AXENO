# 档案分类体系与保管期限（示例占位，落地时按本单位规范替换）

> 把你单位的真实档案门类、判定标准、保管期限写在这里。SKILL.md 的分类表会指向本文件。

## 门类判定标准（示例）

### 文书档案（门类码 WS）
- 涵盖：上级来文、本单位发文、请示批复、会议纪要、规章制度
- 保管期限：涉及重大决策/历史凭证 → 永久；一般业务 → 30 年；事务性 → 10 年

### 财务档案（门类码 CW）
- 涵盖：会计凭证、账簿、财务报表、审计报告、经济合同
- 保管期限：凭证/账簿 → 30 年；年度报表 → 永久

### 业务档案（门类码 YW）
- 涵盖：办事申请材料、审批表、发放证照、业务台账
- 保管期限：按对应业务规定

### 照片/影像档案（门类码 ZP）
- 涵盖：现场照片、扫描件、音视频
- 保管期限：按记录内容的重要程度定

## 判定原则
- 一份材料同时涉及多门类时，按**主要内容**归类，并在清单备注交叉关系。
- 期限就高不就低：同一份材料命中多个期限时取最长。
- 判不准的门类/期限 → ⚠️ 标注，转人工复核，不硬归。
