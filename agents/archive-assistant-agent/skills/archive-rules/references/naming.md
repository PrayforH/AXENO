# 归档命名规范与目录结构（示例占位，落地时按本单位规范替换）

> 把你单位的真实命名规范写在这里，让归档后的文件名统一、可检索。

## 文件命名格式（示例）

```
<年度>-<门类码>-<流水号>-<主题简述>.<原扩展名>
```
- 年度：4 位，按文件形成年份（如 2026）
- 门类码：见 classification.md（WS/CW/YW/ZP …）
- 流水号：4 位，同门类同年度内递增（0001 起）
- 主题简述：不超过 20 字，去掉特殊字符
- 扩展名：**保留原扩展名，不转换格式**

示例：`2026-WS-0007-关于XX工作的通知.pdf`

## 归档目录结构（示例）

```
归档根/
└── <年度>/
    └── <门类中文名>/
        └── <规范文件名>
```

## 规则
- **不改原件内容**，只改文件名与所在目录。
- 重名冲突：流水号顺延，不覆盖既有文件。
- 无法确定年度/主题的 → ⚠️ 标注，暂不重命名，转人工。
