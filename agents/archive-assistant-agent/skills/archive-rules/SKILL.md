# 档案归档规则 Skill（archive-rules）

> ⚠️ 这是【模板·请替换成你单位的真实归档规范】——**门类码/保管期限均为占位示例，照搬会导致定级错误、违反档案规定，上线前必须替换**。归档前先看这份规则，按统一口径分类/命名，不凭主观感觉。
> 大块的原始资料（分类体系、命名细则）放 `references/`，本 SKILL.md 做索引。

## 工作流程

### 第一步：盘点与识别
- `list_directory` / `glob` 盘点待归档文件；`read_file` / `read_many_files` 读文档；**扫描件/照片用 `read_visual_file`** 识别内容。
- 文件多时用 `Agent` 委派给 `file_classifier` 子代理并行判定门类。

### 第二步：分类定级
- 对照本 Skill 与 `references/classification.md`，判定每份文件的**门类**与**保管期限**；拿不准用 `ask_user`，不硬猜。

### 第三步：重命名 + 归档
- 按 `references/naming.md` 规范生成新文件名；`run_shell_command` 建门类目录并 `mv` 归位。**只移动/重命名，不改内容。**

### 第四步：出归档清单
- `write_file` 生成清单：原文件 → 新路径/新名、门类、保管期限、依据、关键元数据。

## 关键原则
- **原件不可改**：只分类/重命名/移动，绝不修改文件内容。
- **分类必有据**：门类/期限判定要对得上规则具体条目。
- **存疑必标注**：识别不清、分类拿不准的标 ⚠️，转人工复核，不硬填。
